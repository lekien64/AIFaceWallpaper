# AI FACE WALLPAPER

Android app for Xiaomi 17 / HyperOS 4.

## Project status
This is an initial Android project scaffold.
The actual AI face-swap model and video rendering engine are not implemented yet.

## Planned features
- Fully offline AI processing.
- Face Scanner with camera and gallery.
- Guided 7-angle face capture.
- Image quality and face consistency checks.
- Review Before Create mode.
- Optional Auto Create.
- Local face profile storage.
- Live wallpaper support.

## Build
GitHub Actions builds the debug APK.
Open Actions and run Build Android APK.
